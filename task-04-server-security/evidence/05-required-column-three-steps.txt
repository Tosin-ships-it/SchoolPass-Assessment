1. THE THREE-STEP ZERO-DOWNTIME PROTOCOL
--------------------------------------------------------------------------------
When adding a required (NOT NULL) column to a populated production table, a single
destructive migration causes service failure (as proven in Evidence 04).
The industry-standard zero-downtime protocol decomposes the change into three
discrete, safe phases:

  Phase 1: Add the column as OPTIONAL (nullable).
  Phase 2: BACKFILL existing rows with valid data (or default values).
  Phase 3: Enforce the REQUIRED (NOT NULL) constraint once zero nulls remain.
