Stage 1 verifies against trimmed input. If verification fails and whitespace was entered, Stage 2 verifies untrimmed input to support legacy accounts and seamlessly updates hash.

Why Trim but Never Lowercase? Copying a password commonly introduces accidental leading/trailing spaces from text editors, which users cannot diagnose. Trimming fixes this error safely. Conversely, lowercasing a password destroys entropy and violates user intent, as character casing is deliberately chosen.
