1. FAILURE SCENARIO OVERVIEW
--------------------------------------------------------------------------------
When scaffolding a project with an AI agent or automated CLI (such as running 
`npx create-next-app SchoolPass` from within a repository directory named `SchoolPass`), 
the tool frequently creates an unintended nested folder structure:
  <repo-root>/
    └── SchoolPass/
          ├── package.json
          └── src/

When a developer or automated build pipeline subsequently runs commands from the 
repository root (`<repo-root>/`), npm fails because no `package.json` exists in 
the current working directory.
