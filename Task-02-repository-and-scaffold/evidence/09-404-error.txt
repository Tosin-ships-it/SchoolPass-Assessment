1. FAILURE SCENARIO OVERVIEW
--------------------------------------------------------------------------------
In web application development, 404 Not Found errors and blank pages frequently 
stem from routing discrepancies:
- Naming convention errors (e.g. App Router files named `index.js` or `handler.js` 
  instead of `page.tsx`).
- Route path mismatches (e.g. client requests `/health` while the handler is 
  registered at `/api/v1/health` or nested incorrectly).
- Unhandled route fallthrough returning 404 without expected page markup.

To test this failure cleanly without impacting the main SchoolPass application 
running on port 3000, an isolated diagnostic server was initialized on port 3060 
with an intentionally misconfigured routing table omitting `/health`.
