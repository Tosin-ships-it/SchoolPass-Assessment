================================================================================
PHASE 4: COMPARATIVE ANALYSIS (git revert vs git reset)
================================================================================
1. `git revert <commit-id>`:
   - Mechanism: Creates a new forward commit that applies the inverse diff of the target commit.
   - Advantages: Non-destructive, safe for shared remote branches, leaves complete audit trail.
   - Compliance: Mandated for enterprise production systems (SOC2 / ISO 27001 auditability).

2. `git reset --hard <commit-id>`:
   - Mechanism: Moves branch HEAD pointer backwards and obliterates intermediate commits from working tree.
   - Hazards: Destroys uncommitted work, desynchronizes remote branch tracking, requires dangerous `git push --force`.
   - Assessment Rule: Prohibited on SchoolPass main repository.
