EXECUTIVE SUMMARY
================================================================================
This test demonstrates that an attacker can completely bypass client-side validation
rules by transmitting direct HTTP requests to the registration API endpoint.

Client-Side Rules Bypassed:
1. Name Structure Rule: Client enforces a two-word requirement (first and last name)
   where each word is >= 2 characters. The direct request submitted "BypassUser" (1 word).
2. Legal Terms Acceptance: Client enforces an affirmative checkbox click for Terms
   and Privacy Policy before enabling/allowing submission. The direct request omitted
   terms acceptance entirely.
3. Password Confirmation: Client enforces password confirmation match. The direct
   request omitted confirmPassword entirely.

Server-Side Boundaries Enforced:
1. Zod schema validation (email structure, minimum password length).
2. Pwned password check (HaveIBeenPwned API integration).
3. IP rate limiting (auth_register bucket).
4. Student number lookup in admission registry.
