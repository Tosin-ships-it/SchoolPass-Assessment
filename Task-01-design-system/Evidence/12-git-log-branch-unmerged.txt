================================================================================

Why This Is the Whole Argument for Token Referencing:

When colour roles reference palette primitives through variables, updating the brand color at the source automatically propagates across the entire design system and maintains global visual coherence. When a role or component hardcodes a raw hex value instead of referencing the palette, it silently decouples from the system and remains frozen when the palette updates. This deliberate regression demonstrates how broken token referencing creates immediate visual fragmentation, proving that tokens must strictly reference primitives to ensure the interface can be rebranded or updated from a single source of truth.
